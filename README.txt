DÓMINI JOYERÍA — CATÁLOGO ONLINE

Este sitio está preparado para publicarse gratis con GitHub Pages.

Contenido:
- index.html: tienda/catálogo responsive.
- products.json: productos tomados de PLANILLA.xlsx.
- assets/: fotografías extraídas del Excel y las dos fotografías actuales de HYDRA.

FUNCIONES
- Categorías: Aros, Pulseras, Collares, Anillos.
- Ficha de producto con 1–2 fotografías, descripción, material, precio y stock.
- Carrito con cantidades y total.
- El carrito genera el pedido por WhatsApp.
- Los pagos online quedan para una segunda etapa.

PUBLICAR EN GITHUB PAGES
1. Crea un repositorio nuevo en GitHub.
2. Sube TODO el contenido de esta carpeta manteniendo la estructura.
3. En Settings > Pages, selecciona Deploy from a branch, rama main y carpeta /root.
4. Guarda. GitHub generará la dirección pública del sitio.

NOTA: El número de WhatsApp configurado es el que estaba definido para el proyecto: +56 9 2086 2501.
